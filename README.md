This project provides a seamless online ordering experience for customers while ensuring efficient inventory management for a canteen. A key feature of this system is inventory locking and auto-cancellation. When an order is placed, the stock for the selected items is immediately reserved. If the order is not confirmed within 15 minutes, it is automatically cancelled, and the reserved stock is returned to the inventory.
